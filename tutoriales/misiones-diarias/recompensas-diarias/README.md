# Recompensas Diarias

## Recompensas por actividad ( RC )

Usa — /rc — cada 15 minutos para reclamar tus recompensas.

Este sistema permite avanzar a través de varios niveles hasta el nivel 25 como máximo. Cada nivel tiene requisitos específicos relacionados con tiempo de juego, y otros logros dentro del servidor. Para subir de nivel, los jugadores deben cumplir con los requisitos del comando — /rpa —&#x20;

## Sistema de Rangos ( RPA )

El servidor utiliza una jerarquía de **niveles** (Nivel 1 a Nivel 25) donde los jugadores pueden ascender al completar ciertos requisitos. Estos niveles están disponibles desde el dia 1, y los requisitos están basados en logros que cualquier persona puede cumplir, simplemente jugando.

### Cada nivel puede tener o nó, estos requisitos:

* **Votos**: La cantidad de votos necesarios para ascender al nivel.
* **Permiso**: El permiso necesario para alcanzar este nivel (por ejemplo, completar cierto % de Pokedex., haber subido un Pokemon al nivel 100, Completar nuestras TorreBatalla hasta cierto piso, y diferentes novedades).
* EnderCrystal: Cada Nivel siempre necesita una cantidad especifica de este item, puedes craftearlo, y comprar los drops en el — /warp tienda —&#x20;
* **Coste**: El coste de PokeDollares para ascender el nivel.
* **Estadistica**: Los requisitos de estadísticas del jugador para alcanzar el nivel, como tiempo de juego, distancia recorrida, o cantidad de saltos, o cualquier estadistica de tu partida que haya sido considerada.
