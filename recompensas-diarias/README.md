# Recompensas Diarias

## Recompensas por actividad ( RPA )

Este sistema permite a los jugadores de nuestro servidor avanzar a través de varios niveles de actividad. Cada nivel tiene requisitos específicos relacionados con tiempo de juego, y otros logros dentro del servidor. Para subir de nivel, los jugadores deben cumplir con ciertos requisitos.

## Sistema de Rangos ( Rank Up )

El servidor utiliza una jerarquía de **niveles** (Nivel 1 a Nivel 25) donde los jugadores pueden ascender al completar ciertos requisitos. Estos niveles están disponibles desde el dia 1, y los requisitos están basados en logros que cualquier persona puede cumplir, simplemente jugando.

### Cada nivel puede tener o nó, estos requisitos:

* **Votos**: La cantidad de votos necesarios para ascender al nivel.
* **Permiso**: El permiso necesario para alcanzar este nivel (por ejemplo, completar cierto % de Pokedex. O completar alguna de nuestras misiones).
* Objetos: Los objetos que el jugador debe tener en su inventario para ascender a este nivel.
* **Coste**: El coste en PokeDollares para ascender el nivel.
* **Estadistica**: Los requisitos de estadísticas del jugador para alcanzar el nivel, como tiempo de juego, distancia recorrida, o cantidad de saltos, entre muchisimas opciones que hemos guardado.
