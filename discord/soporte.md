# 🎟️ Soporte

Los tickets son una forma de contactar con el staff para resolver problemas o hacer preguntas.

**`.new` 🆕**

* **Descripción:** Crear un nuevo ticket.
* **Sintaxis:** `.new [razón]`
* **Ejemplo:** `.new Necesito ayuda con mi cuenta`

**`.bugreport` 🐛**

* **Descripción:** Reportar un error en el servidor.
* **Sintaxis:** `.bugreport [descripción del error]`
* **Ejemplo:** `.bugreport El comando .daily no funciona`

**`.report` 🚨**

* **Descripción:** Reportar a un usuario.
* **Sintaxis:** `.report @usuario [razón]`
* **Ejemplo:** `.report @Usuario1 Está spameando en el chat`

**`.ip` 🌐**

* **Descripción:** Ver la IP del servidor de Minecraft.
* **Sintaxis:** `.ip`
* **Ejemplo:** `.ip`

**`.status` 🟢**

* **Descripción:** Ver el estado de un servidor de Minecraft.
* **Sintaxis:** `.status`
* **Ejemplo:** `.status`
