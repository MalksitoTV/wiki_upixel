# ⚙️ Comandos Discord

## 🌟 Comandos de Experiencia

`.rank @usuario` → Muestra el rango de un usuario

`.level @usuario` → Muestra el nivel de experiencia de un usuario

`.leveltop` → Muestra el ranking de niveles

`.invites` → Conoce tus invitaciones al servidor

`.invitetop` → Muestra el ranking de invitaciones

`.vctop` → Muestra el ranking de usuarios en canales de voz

## 🛡️ Soporte

`.new` → Crea un ticket de soporte

`.tickets` → Muestra tus tickets de soporte

`.bugreport [detalle]` → Reporta un error

## **🛠️ Utilidades**

* `.umbreon [pregunta]` → Te responderá Umbreon de forma totalmente al azar!
* `.logro [texto]` → Genera un logro estilo Minecraft
* `.avatar @usuario` → Muestra el avatar de un usuario
* `.ayuda` → Muestra la lista de comandos y ayuda del bot
* `.sorteos` → Conoce los sorteos en curso
* `.links` → Muestra los enlaces importantes del servidor
* `.google [búsqueda]` → Busca algo en Google
* `.ip` → Muestra nuestra/s IP
* `.math [expresión]` → Resuelve una operación matemática
* `.ping` → Muestra la latencia del bot
* `.paste [texto]` → Crea un paste de texto
* `.remindme [recordatorio] [tiempo]` → Crea tu propio recordatorio
* `.suggest [sugerencia]` → Envía una sugerencia al servidor

## **💰 Economía**

* `.uc` → Muestra tu saldo de monedas
* `.uctop` → Muestra la tabla de posiciones de monedas
* `.daily` → Reclama la recompensa diaria
* `.weekly` → Reclama tu recompensa semanal
* `.work` → Realiza un trabajo para ganar monedas o experiencia
* `.pay @usuario [cantidad]` → Envía monedas a otro usuario
* `.shop` → Accede a la tienda del bot
* `.buy [objeto]` → Compra un objeto

## 🎲 Casino Virtual

* `.gamestats [juego]` → Muestra estadísticas de un juego
* `.gametop` → Muestra el ranking de jugadores
* `.rps [elección]` → Juega piedra, papel o tijera GRATIS !

## **🎵 Música**

* `.play [nombre/url]` → Reproduce música
* `.pause` → Pausa la canción actual
* `.queue` → Muestra la lista de canciones

## **📌 Otros**

* `.accept` → Acepta algo
* `.add [elemento]` → Agrega algo
* `.channelinfo [#canal]` → Muestra información sobre un canal
